# OpenDocAgent

An open-source agentic workflow tree to take specialized Markdown generated by Agents and convert it into LaTeX (PDF), PPTX, and DOCX, applying organizational templates.

## Features (In Progress)
- **Markdown Parsing:** Uses `markdown-it-py` for parsing agent outputs with custom frontmatter.
- **LaTeX/PDF:** Uses `pylatex` for high-quality document generation.
- **PowerPoint:** Uses `python-pptx` to map sections to slides.
- **Word:** Uses `python-docx` to map markdown elements to word styles.
- **Templates:** Supports `.potx` and `.dotx` organizational templates.

## Installation

```bash
pip install .
```

## Usage

```bash
opendoc build my_report.md --format pdf
```
