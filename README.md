# OpenDocAgent

An open-source agentic workflow tree to take specialized Markdown generated by Agents and convert it into LaTeX (PDF), PPTX, and DOCX, applying organizational templates.

## Features
- **Strict Python >= 3.12 Typing**: Modern PEP 695 type aliases, `TypedDict`, and structured diagnostics.
- **Agent-Native FastMCP Server**: Built-in Model Context Protocol server (`opendoc serve-mcp`) exposing tools, resources, and prompts to Claude, Cursor, and agent frameworks.
- **In-Memory & File Pipeline**: Generate documents to disk or stream raw bytes in-memory (`build_bytes()`).
- **Markdown Parsing:** Uses `markdown-it-py` for parsing agent outputs with custom YAML frontmatter.
- **LaTeX/PDF:** Uses Pandoc / pdflatex for high-quality document generation.
- **PowerPoint:** Uses `python-pptx` to map sections to slides with organizational templates (`.potx`).
- **Word:** Uses `python-docx` to map markdown elements to word styles (`.dotx`).

## Installation

Requires Python >= 3.12.

```bash
# Basic CLI
pip install .

# With FastMCP server support
pip install ".[mcp]"
```

## Usage

### CLI

```bash
# Compile a document
opendoc build my_report.md --format pdf

# Lint a document for style compliance
opendoc lint my_report.md

# Launch the FastMCP server for AI agents
opendoc serve-mcp --transport stdio
```

### FastMCP Server for AI Agents
Connect OpenDocAgent to your agent desktop or orchestrator (e.g. Claude Desktop, Antigravity) via stdio or SSE:
```json
{
  "mcpServers": {
    "opendocagent": {
      "command": "opendoc",
      "args": ["serve-mcp", "--transport", "stdio"]
    }
  }
}
```
Exposes:
- Tools: `lint_document`, `compile_document`, `get_style_guidelines`, `list_supported_formats`
- Resources: `opendocagent://docs/syntax`, `opendocagent://docs/architecture`
- Prompts: `draft_document`
