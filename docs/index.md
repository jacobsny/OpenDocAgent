# OpenDocAgent Documentation

Welcome to the OpenDocAgent documentation site!

OpenDocAgent is a robust pipeline that allows AI Agents (and humans) to generate highly formatted, branded PPTX, DOCX, and PDF documents using universally agreed-upon Markdown syntax.

## Why use OpenDocAgent?
- Designed for Agentic workflows (clean Markdown AST parsing).
- Strict archetypal enforcement (`style: executive` vs `style: technical`).
- First-class support for Jinja2 dynamic payloads and Mermaid.js diagrams.

See the **Markdown Syntax Guide** for instructions on how to prompt your LLMs to generate compatible Markdown.
