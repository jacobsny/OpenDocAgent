# Organizational Templates

This directory contains templates for PDF (LaTeX), PPTX, and DOCX generation.

## TODO: Rich Formatting Language
Currently, templates are basic. We need to design and implement a rich formatting language to support full-featured PowerPoints and complex document structures. This language will be embedded in the Agent's Markdown output (e.g. via YAML frontmatter or custom directives).

### Supported Formats
- `.potx` for PowerPoint
- `.dotx` for Word
- `.tex` or `.sty` for LaTeX
